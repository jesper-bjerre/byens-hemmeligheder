# Gåder Admin – TestFlight release-assets

Pakken indeholder:

- `AppIcon.appiconset`: Xcode-kompatibel appikonmappe med det valgte Koncept A.
- `Branding`: appikonmaster, udviklings-previewstørrelser og launch-screen-reference.
- `NavigationIcons`: specialillustrationer til kort, opgave, spor, hint, foto, lyd, GPS og publicering.
- `EmptyStates`: illustrationer til ingen opgaver, vælg lokation og klar til test.
- `AppStoreScreenshots`: seks separate screenshot-mockups i 1290 × 2796 px.
- `ReferenceBoards`: de tre samlede designboards.
- `Metadata`: forslag til TestFlight- og App Store-tekst.

## Vigtigt før App Store-indsendelse

Screenshot-filerne er designmockups. Til den endelige App Store-udgivelse bør de
erstattes med faktiske screenshots fra den færdige app, så de præcist viser den
funktionalitet, brugeren får.

Standardhandlinger som tilbage, gem, plus, søg, filter, indstillinger og del bør
implementeres med SF Symbols frem for billedfiler.

Kontrollér alle tekster, funktioner, tilladelser, loginforhold og privatlivsoplysninger
i App Store Connect før indsendelse.
