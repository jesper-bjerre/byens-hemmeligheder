# Gåder Admin – forslag til TestFlight- og App Store-metadata

## Appnavn
Gåder Admin

## Undertitel
Opret og administrér byens gåder

## Kort beta-beskrivelse
Gåder Admin er værktøjet til quizmastere i Byens Gåder. Opret nye opgaver,
redigér fortællinger og spor, vælg GPS-position, tilføj billeder og lyd,
test opgaven og gør den klar til udgivelse.

## Hvad skal testes?
- Opret en ny opgave
- Placér opgaven på kortet
- Tilføj fortælling, spørgsmål, svar og hints
- Tilføj billede og lyd
- Gem som kladde
- Test opgaven i spillerappen
- Udgiv og redigér en eksisterende opgave

## Nøgleord
gåder, quizmaster, escape room, opgaver, byvandring, lokation, administration

## Visuel retning
Koncept A er valgt som appikon:
en gylden kortmarkør med nøglehul og en blyant på turkis kortbaggrund.
Ikonet viser både lokation, gåde og redigering.
